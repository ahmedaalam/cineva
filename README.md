## ⚙️ Getting Started

### 1. Clone the repo

```bash
git clone https://github.com/ahmedaalam/cineva.git
```

### 2. Install dependencies

```bash
npm install
```

### 3. Run the app

```bash
npm run dev
```

---

## 🔑 Environment Variables

Create a `.env` file in the root directory and add:

```env
VITE_TMDB_API_KEY=your_api_key_here
```
